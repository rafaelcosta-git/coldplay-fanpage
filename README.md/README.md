# Coldplay Fanpage (PHP + MySQL)

## Como correr localmente (XAMPP)
1. Importar a base de dados (SQL) no phpMyAdmin
2. Copiar `php/db.example.php` para `php/db.php`
3. Ajustar credenciais no `php/db.php`
4. Abrir no browser: http://localhost/fullstackdev/Aulas-HTMLCSS/coldplay-fanpage/

## Funcionalidades
- Registo e login (sessões)
- Loja (produtos em MySQL)
- Carrinho + checkout (orders + order_items)
- Área admin (role = admin)
